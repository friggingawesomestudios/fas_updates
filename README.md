# fas_updates

Version info for Frigging Awesome Studios Maya tools. AnimPolish and Sticky Mod read these files for Help > Check For Updates.

- `animPolish.json`
- `stickyMod.json`

Each release gets an entry at the top of `releases`, with its version and notes:

```json
{
	"url": "http://joshsobelrigs.com/animpolish2",
	"releases": [
		{"version": "2.0.1", "notes": ["Fixed this", "Added that"]},
		{"version": "2.0.0", "notes": ["First release"]}
	]
}
```

Get AnimPolish at http://joshsobelrigs.com/animpolish and Sticky Mod at https://gum.co/sticky-mod.
